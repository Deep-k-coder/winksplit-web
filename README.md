# WINKSPLIT

**Eco-Friendly Packaging for Indian Businesses**

WINKSPLIT is an Indian eco-friendly paper packaging brand focused on making sustainable packaging easier to source for modern businesses.

## About

WINKSPLIT brings practical paper packaging options, customer-facing pricing, minimum order quantities, bulk enquiries and custom-printing conversations into one simple B2B experience.

The website is designed for restaurants, cafes, cloud kitchens, caterers, retailers, food businesses, distributors and other growing Indian businesses looking for paper-based packaging solutions.

## Product Categories

- Paper Bottles — 250 ml, 500 ml, 750 ml
- Paper Plates — 6 inch, 8 inch, 10 inch, 12 inch
- Kraft Paper Bowls — 250 ml, 500 ml, 750 ml
- Kraft Food Boxes — 500 ml, 750 ml, 1000 ml
- Napkins & Tissue — 1-Ply, 2-Ply and custom printed options
- Honeycomb Paper Roll — selected 80 GSM sizes

Product specifications, customer prices and MOQs should be maintained from the approved WINKSPLIT product catalog. Internal purchase costs and supplier information must never be exposed in the customer-facing website.

## Website Features

- Premium eco-friendly visual identity
- Responsive desktop, tablet and mobile design
- Product catalog with size/capacity and customer pricing
- MOQ and bulk-order information
- Custom-printing enquiry flow
- WhatsApp enquiry/order CTA

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
